# 🤝 Community Resources

This directory is where you contribute resources to earn **25 points** on the AutoGrader.

## How to Contribute

1. Create a new `.md` file (e.g., `my-favorite-arduino-tutorial.md`)
2. Add a link, summary, or tutorial related to Arduino, electronics, or IoT
3. Commit and push — the AutoGrader will detect it automatically

## Ideas

- A helpful Arduino tutorial you found online
- A wiring diagram tip that saved you time
- A sensor datasheet summary
- A Sensai prompt that worked really well
- A code pattern you discovered (e.g., debouncing, non-blocking timing)

> ⚠️ Your file must be a `.md` file and must NOT be named `README.md`.
