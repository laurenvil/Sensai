# 🌐 Community Resources

This folder is maintained by students. Every resource here was contributed by a classmate who found it helpful.

**To earn your 25 community points:** Add a `.md` file here with a resource that helped you in this course.

---

## How to Contribute

1. Create a new file: `your-name-resource.md`
2. Add a title, link, and 2–3 sentences explaining why it's useful
3. Commit and push — the AutoGrader will detect your file
