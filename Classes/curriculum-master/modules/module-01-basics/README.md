# 📚 Module 01 — Git Basics & Open Classroom Orientation

> **Estimated Time:** 2–4 hours  
> **AutoGrader:** Enabled — you'll see ✅ or ❌ after every `git push`

---

## 🎯 Learning Objectives

By the end of this module, you will be able to:

1. Explain what version control is and why it matters
2. Clone a repository and create a feature branch
3. Make commits with meaningful messages and push to GitHub
4. Open a Pull Request and respond to code review feedback
5. Pass the AutoGrader by implementing a required function

---

## 🛤️ Choose Your Path

### Path A — Guided 📖
Follow these steps **in order**:

1. **Read** `resources.md` — watch the linked intro video first (15 min)
2. **Edit** `starter-code/app.py` — implement the `hello()` function
3. **Create** `learning-contract.md` using the template below
4. **Push** your changes — watch the AutoGrader run in the Actions tab
5. **Open a Pull Request** when the AutoGrader shows ✅

### Path B — Explorer 🚀
Use the core Git concepts to build something original:

- A personal project tracker
- A collaborative recipe book
- A study notes repository with PR-based contributions
- Your own idea? Open a Learning Contract issue and describe it!

### Path C — Expert 🧠
Improve this curriculum or the AI that powers it:

- Find a bug or confusing section → open a [Bug Report issue](../../../../issues/new/choose)
- Propose an improvement → open a [Curriculum Improvement issue](../../../../issues/new/choose)
- Submit a Pull Request to `curriculum-master` with your changes
- **Improve the AI prompts:** Edit `.github/prompts/*.prompt.yml` to make the AI generate better modules, explain failures more clearly, or give better review guidance — then submit a PR
