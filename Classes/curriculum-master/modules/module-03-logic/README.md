# 🧠 Module 03 — Variables & Logic

> **Estimated Time:** 1–2 class periods  
> **AutoGrader:** Enabled

## 🎯 Learning Objectives

1. Declare variables and constants in Arduino C++
2. Use `digitalRead()` to detect button presses
3. Write `if/else` statements to make decisions in code
4. Understand pull-up resistors and `INPUT_PULLUP`
