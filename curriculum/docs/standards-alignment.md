# Standards Alignment — CSTA & NGSS

Maps each module to **CSTA** and **NGSS** standards.

---

## Module Alignment

| Module | CSTA Standards | NGSS Standards |
|--------|---------------|----------------|
| **01 — Welcome to Arduino** | 1B-CS-02 (HW/SW systems), 2-CS-02 (design projects) | — |
| **02 — Your First Circuit** | 1B-CS-02 (HW/SW together) | MS-ETS1-1 (design constraints), MS-ETS1-4 (iterative testing) |
| **03 — Variables & Logic** | 2-AP-11 (variables), 2-AP-12 (control structures), 2-AP-17 (testing) | — |
| **04 — Reading the World** | 2-AP-11 (variables/map) | MS-PS4-3 (digitized signals), MS-ETS1-4 (iterative testing) |
| **05 — Sensing the Environment** | 2-AP-13 (decomposition), 3A-CS-02 (abstraction) | MS-ETS1-2 (evaluate solutions) |
| **06 — Talking to the Computer** | 2-NI-04 (protocols), 2-AP-12 (control structures) | MS-PS4-3 (digital encoding) |
| **07 — Making Things Move** | 2-AP-12 (loops), 2-AP-13 (decomposition) | HS-PS4-5 (wave behavior / PWM) |
| **08 — Advanced Communication** | 2-NI-04 (I2C/SPI protocols), 3A-CS-02 (abstraction levels) | MS-PS4-3 (digital transmission) |
| **09 — IoT Projects** | 3A-AP-13 (prototypes), 2-CS-02 (HW+SW systems) | HS-ETS1-2 (design solution), HS-ETS1-3 (evaluate solution) |
| **10 — Demo Day** | 3A-AP-17 (decompose), 2-AP-17 (test/refine) | HS-ETS1-2, HS-ETS1-3 (design + evaluate) |

## CSTA Standards Reference

| Standard | Description |
|----------|-------------|
| 1B-CS-02 | Model how computer hardware and software work together as a system |
| 2-CS-02 | Design projects that combine hardware and software components |
| 2-AP-10 | Use flowcharts and/or pseudocode to address complex problems |
| 2-AP-11 | Create clearly named variables that represent different data types |
| 2-AP-12 | Design and iteratively develop programs that combine control structures |
| 2-AP-13 | Decompose problems into smaller components through systematic analysis |
| 2-AP-17 | Systematically test and refine programs using a range of test cases |
| 2-NI-04 | Model the role of protocols in transmitting data |
| 3A-CS-02 | Compare levels of abstraction between application software, system software, and hardware |
| 3A-AP-13 | Create prototypes that use algorithms to solve computational problems |
| 3A-AP-17 | Decompose problems into smaller components through systematic analysis |

## NGSS Standards Reference

| Standard | Description |
|----------|-------------|
| MS-ETS1-1 | Define the criteria and constraints of a design problem |
| MS-ETS1-2 | Evaluate competing design solutions using a systematic process |
| MS-ETS1-4 | Develop a model to generate data for iterative testing and modification |
| MS-PS4-3 | Digitized signals are a more reliable way to encode and transmit information |
| HS-ETS1-2 | Design a solution to a complex real-world problem |
| HS-ETS1-3 | Evaluate a solution to a complex real-world problem based on criteria |
