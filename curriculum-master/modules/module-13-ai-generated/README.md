# Module 13: Bluetooth Low Energy

## Learning Objectives
By the end of this module, you will be able to:
- Understand the fundamentals of Bluetooth Low Energy (BLE) technology.
- Implement BLE communications in your Arduino projects.
- Build a project that demonstrates BLE capabilities using the Arduino Uno Q platform.

## Paths
This module offers three distinct learning paths. Please select one based on your interests and the desired challenge level:

### Path A: Basic BLE Communication
- Learn about BLE concepts and create a simple project that sends sensor data over BLE.

### Path B: BLE Device Pairing
- Implement pairing between devices and understand security protocols. Create a project where your Arduino Uno Q can be controlled by a smartphone app.

### Path C: Advanced BLE Features
- Dive into advanced BLE functionalities, like data characteristics and notifications. Develop a multi-device BLE setup that communicates with multiple sensors.

## Wiring Instructions
1. Connect your Arduino Uno Q to a BLE module (e.g., HM-10).
2. Ensure that the RX pin of the BLE module is connected to the TX pin of the Arduino and vice versa.
3. Connect the module's VCC to the 3.3V output on the Arduino, and GND to GND.

## Learning Contract
- Complete the objectives for your chosen path.
- Submit your code via a GitHub Pull Request (PR).
- Collaborate with classmates by reviewing each other's PRs.
- Engage in at least one discussion on the project's forum.
